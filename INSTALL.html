Verge Card

0.3.0 Beta 1（构建 16，自动配置版）· 原生桌面小组件 · Apple 芯片 · macOS 14+

此包使用 Apple Development 开发签名，未经 Apple 公证。使用前需在每台 Mac 完成首次配置。Verge Card 不包含 Clash、VPN 服务或订阅。

安装与首次配置

  1. 在待安装的 Mac 浏览器中打开 GitHub Release 页面，从 Assets 下载附件。候选草稿仅仓库拥有者登录后可见；聊天里的本机文件路径链接不作为跨电脑分发入口。先安装、启动并配置好 Clash Verge Rev。
  2. 升级时先从菜单栏退出旧版 Verge Card（无需退出 Clash）。推荐下载 ZIP，双击解压，打开“Verge Card”文件夹，将其中的 Verge Card.app 拖入“应用程序”，从该文件夹首次打开。另提供文件名带 hfsplus 的 DMG：双击挂载后将 App 拖入 Applications。
  3. 若系统阻止打开，先尝试启动一次，再到“系统设置 → 隐私与安全性 → 仍要打开”，完成本人验证并确认。参见 Apple 官方流程。无需关闭 Gatekeeper 或 SIP；受管理的 Mac 可能不允许添加例外。
  4. 确认页面顶部显示 0.3.0 Beta（16）。进入设置页会自动检查配置，重新进入和授权返回也会自动继续；无需先点连接按钮。自动读取当前用户的 Clash 配置；若目录不同，选择包含 verge.yaml 与 clash-verge.yaml 的目录，选好后自动保存并连接；手动修改路径后按回车或点击“自动配置并连接”。
  5. 在下拉列表选择规则模式中负责当前连接的主节点组。该选择只影响延迟读取，不切换 Clash 节点。
  6. 在“系统设置 → 隐私与安全性 → 辅助功能”允许 Verge Card。返回后程序自动继续：沿用有效快捷键、补齐缺失或冲突项并保存核对，无需你录入组合键。首次自动配置会短暂打开 Clash 热键设置；期间不切换代理、TUN、模式或节点。系统授权须本人确认，应用无法自动授予。
  7. 允许 Verge Card 登录启动后，关闭设置窗口。桌面空白处右键 → 编辑小组件 → 搜索 Verge Card → 添加小号、中号或大号。

三种尺寸

尺寸显示与交互
小号两个开关、模式选择；右上角测速，悬停查看结果。
中号两个开关、模式选择、延迟数值；右上角测速。
大号两个开关、模式选择、节点延迟和网速快照；右上角测速。

点击右上角测速图标会先读取真实状态，再测试当前节点，完成后更新所有尺寸，不打开设置窗口。品牌入口打开设置页。网速仅为上次采样快照，设置页不再提供网速采样按钮，不能作为实时流量表。

后台与刷新

主程序必须运行，才能响应小组件；关闭设置窗口不会退出。自动更新请求默认约 30 分钟，实际时机由系统决定。空闲时等待事件与请求，不持续秒级轮询、不持续采集网速。退出 Verge Card 会中断小组件控制连接，不会退出 Clash。

常见问题

  • DMG 提示磁盘无法读取：不要点击“初始化”；推出该镜像，改用本次提供的 ZIP。旧候选镜像使用 APFS，新 DMG 明确使用 HFS+。本次同时修复自动配置流程，应用为构建 16；异机兼容性仍待验收。
  • 图库中找不到：确认应用已放入“应用程序”并成功打开，再关闭并重新打开“编辑小组件”。
  • 权限不足或按钮无响应：从品牌入口打开设置，检查辅助功能授权，然后点击“自动配置并连接”重试。当前适配 Clash 中文、英文热键界面；无法识别界面时会停止并提示，不会盲目操作其他开关。
  • 没有节点延迟：确认 Clash 已连接，并为规则模式选择了有效主节点组。直连或没有可测试节点时不会编造结果。
  • 后台未连接：打开应用程序中的 Verge Card，检查登录启动状态。不要同时运行多个不同路径的副本。
  • 反馈：提供系统版本、Clash 版本和错误提示，不要上传订阅、密钥或完整配置。

隐私与许可

配置和密钥留在本机主程序，密钥不写入小组件共享缓存。无 Verge Card 账号、遥测或云端服务。测速由本机 Clash 访问其配置的测速地址。Yams 与 LibYAML 许可见随包附带的 第三方许可.txt 及应用资源中的 ThirdPartyNotices.txt。

验收边界

此版本为 Beta。真实代理、TUN、规则/全局切换未在开发电脑上操作验收；相关逻辑使用模拟端验证。异机安装和组件交互结果以 Release 页面记录为准。无须 Xcode 或 Apple 开发者账号；此包不支持 Intel Mac、iOS 或其他 Clash 分支。
